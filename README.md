# 🚀 Lema

A modern, cross-platform **Social Media Management, Publishing Queue, and AI Content Studio** built with Flutter for **macOS**, **Windows**, **iOS**, **Android**, and **Web**.

---

## ✨ Features

- **📱 Multi-Platform Social Media Simulator:** Interactive Apple device frame simulating posts and live video playback for **TikTok**, **Instagram Reels / Posts**, **Facebook**, and **YouTube Shorts**.
- **🎬 Real Media Engine:** Upload and preview local images and playable video reels with tap-to-pause and sound toggles.
- **⏱️ Sequential Publishing Queue (Buffer / Crowdfire style):** Preset queue slots (Morning Peak, Lunch Break, Evening Prime, Late Night Scroll) with instant "Share Now" dispatches.
- **📅 Interactive Visual Calendar:** Month & 2-week view powered by `table_calendar` with platform-specific badges and video icons.
- **🤖 AI Content Studio (Gemini Engine):** 60-second video hooks generator, script problem-secret-hack breakdowns, and 7-day multi-channel content batch planner (ported from `victor-onoja/content_ai`).
- **👤 Multi-Brand Persona Manager:** Dynamic brand persona switching pre-seeded with **Emms Digital Media** (`@emmsdigitalmedia`, Nairobi) as the default testing profile.
- **🎨 Apple HIG Design System:** Native Cupertino styling, SF Pro typography, glassmorphism blur cards, and responsive sidebar navigation.

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (>= 3.6.0)
- Xcode (for macOS & iOS builds)
- Visual Studio (for Windows builds)

### Installation
```bash
git clone https://github.com/wakilibaraka/Lema.git
cd Lema
flutter pub get
```

### Running the App
- **macOS Desktop:** `flutter run -d macos`
- **Web Browser:** `flutter run -d chrome`
- **iOS Simulator:** `flutter run -d ios`
- **Android Emulator:** `flutter run -d android`
- **Windows Desktop:** `flutter run -d windows`
